# europages-b2b-scraper

This is an automated web scraper built with Python and `requests`, designed to extract structured company data from [europages.com](https://www.europages.com/). The goal is to gather high-quality B2B leads by targeting specific industries, countries, and product keywords.

## 🔍 Features

- Keyword-based company search
- Pagination support for deep scraping
- Extracts:
  - Company name
  - Website URL
  - Phone number
  - Industry category
  - Country / Location
- CSV export of all scraped data


## ⚙️ Setup

```bash
git clone https://github.com/invinciblepy/europages-b2b-scraper.git
cd europages-b2b-scraper
pip install -r requirements.txt
```
## 🚀 Usage

``` bash
python main.py -k "your keyword"
```
